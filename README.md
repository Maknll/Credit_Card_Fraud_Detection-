# Credit_Card_Fraud_Detection

## Proje Açıklaması
Bu proje Veri Bilimi İçin İstatistik dersi kapsamında hazırlanmıştır.
Projede Kaggle üzerinde bulunan Credit Card Fraud Detection veri seti 
kullanılarak kredi kartı dolandırıcılığı tespiti gerçekleştirilmiştir.
Makine öğrenmesi modeli olarak Logistic Regression kullanılmış ve model 
performansı istatistiksel yöntemlerle değerlendirilmiştir.

## Kullanılan Kavramlar
-Bernoulli Distribution
-Binomial Distribution
-Normal Distribution
-Central Limit Theorem
-Hypothesis Testing
-Confidence Intervals
-Cross Validation
-Accuracy / Precision / Recall / F1

## Veri Seti
Dataset: Credit Card Fraud Detection
Kaynak: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
Toplam işlem sayısı: 284,807
Fraud işlem sayısı: 492
